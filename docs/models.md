Model is a class deprived from `django.db.models.Model`

Models are written in models.py

`python manage.py makemigrations` has be to ran to generate scripts in the migrations directory

run `python manage.py migrate` to apply

Definition
>Models are a template of a more complex data, where there are multiple values to be transfered. These models can be used in forms, which are tools to send data from front-end to back-end.
